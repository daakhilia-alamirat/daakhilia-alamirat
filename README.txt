موقع داخلية الأميرات الخاصة
==========================
الملف الأساسي: index.html (الموقع كله في ملف واحد، الصور والمحتوى جواه).

التشغيل:
- افتحي index.html في أي متصفح مباشرة.
- أو ارفعيه على أي استضافة (مثل Netlify أو GitHub Pages أو أي استضافة عادية) كملف index.html.

تعديلات سريعة (افتحي الملف بأي محرر نصوص وابحثي عن الكلمة):
- رقم واتساب الحجز: ابحثي عن  const WA=
- الغرف وعدد الأسرّة المتاحة (a) وصورها: ابحثي عن  const ROOMS=
- أماكن الخدمات على الخريطة: ابحثي عن  const PTS=

ملاحظة: خط Cairo بيتحمل من الإنترنت (Google Fonts)، فلازم اتصال بالإنترنت عشان يظهر بشكله الصحيح.
